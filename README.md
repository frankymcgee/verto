 ## About The Project

This custom app for ERPNext was created with the intention of customising ERPNext version 15 instances to allow the following:

• Changing the Map View to show topographical Information

• Updated Geolocation information Displaying

• Better Gantt Viewing Information

• Custom Mobile Browser View

• Addition of a fully developed Work Health & Safety Module
